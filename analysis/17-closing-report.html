The 17 changes — done and verified

28 October 2026. This report covers every change in 16-remaining-changes, which includes the 5 partly fixed items from 15-fix-verification. It covers L1, L2, L3 and Sovereign. No public-site pages were touched, and pricing was not changed.

Answer: all 17 changes are made, and an independent check confirmed each one in the code. The 5 partly fixed items are now fully fixed.
  • Two changes (7 and 16) were incomplete after the first pass. The check caught them and a second pass finished them.
  • Two small side effects the check found were fixed too.
  • One more empty refusal class of the same kind ("Counterparty not verified") was removed.
The type-check, build, Seal v6 test vectors, bundle checks and link crawl all pass. All 87 items listed in reports 11 and 13 are now fixed.
How it was done.
  • Four fixers worked in parallel, each on its own files.
  • For each area, a separate read-only checker traced every change through the code, from screen to API to mock, and graded it Fixed, Partly fixed or Not fixed. Where it found a gap or a side effect, a third agent finished the work.
  • An integrator then ran the type-check, the build and the verifier check scripts.
  • I fixed the leftovers myself, corrected the README, checked the main fixes in the browser and crawled all four levels.
