12DELETE/v1/autonomy/grants/{id}Revoke an agent’s autonomy for an action class — one call by one person (L3)

Built-in MCP tools (34)

#ToolScopeWhat it does
1read.recordsreadList records of a write type, filtered by state or counterparty.
2read.recordreadOne record with its full timeline of receipts.
3read.receiptsreadReceipts in a range, newest first.
4read.receiptreadOne receipt by its number.
5read.evidencereadWhat evidence exists for a range: receipts, checkpoints, timestamps, unanchored head.
6read.proof (L2)readThe inclusion proof and both timestamp tokens for one receipt.
7read.declarationreadThe rulebook or declaration in force, at its explicit version.
8read.rulebook_diffreadThe plain-language difference between two rulebook versions.
9read.meterreadThis month’s governed actions, refusals and allowance used.
10read.approvalsreadApprovals waiting, with who can decide and when they expire.
11read.approval_statusreadThe state of one held call. Long-polls up to 30 seconds. (Also answered as govern.approval_status.)
12read.refusalsreadRefusals by code, rule and agent for a period.
13read.chain_headreadThe chain head: number, hash and the last checkpoint.
14read.agentsreadAgents with their route, status and autonomy.
15read.autonomy (L3)readThe autonomy grants for an agent, per write type.
16read.counterpartiesreadRegistered counterparties and their key fingerprints.
17read.statusreadService status and chain integrity, as the status page shows it.
18read.toolsreadThe tools this agent may call, with their risk tags.
19stage.writestagePrepare a write: validate the arguments and run every pre-write check, without applying anything. Returns a staged_id and what would be decided.
20stage.updatestageChange the arguments of a staged write. The checks run again.
21stage.validatestageCheck arguments against the write type’s schema only.
22stage.simulatestageRun the staged write against the rules in force and a draft version side by side.
23stage.diffstageWhat the write would change in the target record, field by field.
24stage.attach_evidencestageAttach a reference (document id or hash) a person will see when approving.
25stage.commentstageLeave a note for the approver on a staged write.
26stage.liststageStaged writes this agent has open.
27stage.getstageOne staged write, with its checks.
28stage.withdrawstageDrop a staged write. Nothing was applied, so nothing is billed.
29act.writeactCommit a staged write. The full decision path runs again on the same bytes; allowed writes run with a 10-minute credential.
30act.escalateactAsk a person to decide a staged write now, before it is refused.
31act.reverseactReverse a committed write inside its reversal window.
32act.retryactRetry a write refused with a PLATFORM.* code, with the same intent_id.
33act.withdraw_escalationactWithdraw a held call before a person decides.
34act.record_outcomeactCheck and record only: report what happened after your code ran an allowed call.
